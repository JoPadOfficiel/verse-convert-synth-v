# Local pronunciation resources

This release packages no Laya model, tokenizer or ONNX Runtime binary. The
deterministic `verse-lingua-lexical-context-v1` baseline remains available offline.

An eventual qualified package must place `laya/manifest.json` and every
hash-bound asset, calibration and qualification receipt here. Native loading
requires the optional `laya-native` Cargo feature. Preparation-time Python,
canonical checkpoint directories and development caches are never resources.

Default ORT builds, uncalibrated policies, unchecked qualification flags,
unresolved tokenizer redistribution and missing independent benefit evidence
must not be shipped as an activated Laya integration.
